# Запуск как программа (один EXE)

## Вариант 1 — portable EXE (рекомендуется)

1. Установи [Node.js](https://nodejs.org) (LTS).
2. В PowerShell из этой папки: `.\build.ps1`
3. Забирай файл **`pack\dist\Alfabetica.exe`** — это **один portable-файл** (~150–200 МБ): внутри Electron, все уроки и озвучка. **Другие файлы рядом не нужны** — можно скопировать только этот exe на флешку или другой компьютер (Windows 64-bit).

При первом запуске Windows может предупредить про неизвестного издателя — «Подробнее» → «Выполнить всё равно».

При первом запуске Windows может спросить разрешение — это нормально для неподписанных программ.

## Вариант 2 — без сборки

Дважды щёлкни **`Запуск-Алфабэтика.vbs`** в корне `алфабэтика_тест` (откроется в окне браузера без адресной строки).

## Вариант 3 — в браузере

Открой `index.html` через локальный сервер (аудио в `file://` может не работать в части браузеров).
